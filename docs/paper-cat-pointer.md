# 桌面纸猫与指针

电脑上使用重新绘制的紧凑圆角白色箭头，去除长尾柄和彩色装饰，以细灰边和轻阴影保证明暗背景上的可见性；可点击元素使用同款简洁白色手形；文本输入保留原生文本指针，禁用和忙碌状态保留相应语义。

登录页故事栏和登录后首页的纸猫共用 `cat-pointer.js`。沿用原 SVG 路径，拆分为头部（包括耳朵）、身体与课本、面部、眼睛和尾巴图层：头部轻微转向和位移，身体与课本轻轻倾斜，视线和尾巴作小幅呼应。原有眨眼、呼吸、摆尾及点击点头继续保留，分别在嵌套图层上运行。

只在600px以上、支持悬停且指针精细的设备启用。手机沿用原有 SVG 图片。尊重 `prefers-reduced-motion`；关闭跟随动作。指针离开页面或窗口失焦后回正，后台页面停止动画。使用按需 requestAnimationFrame 和缓动收敛，静止后停止循环；滚动和大小变化后重新计算坐标，首页重绘后自动挂载新纸猫。

SVG 通过同源地址加载一次并复用，增强失败时保留原图。无需第三方依赖。
