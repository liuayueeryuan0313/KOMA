# 访问者连接信息

登录页故事栏底部说明的正上方，以及工作区侧边栏底部便笺的正上方，显示 IP、IPv4 / IPv6 和中文国家地区。完整 IPv6 保留在文本和悬停提示中，窄屏只截断视觉显示。IPv6 使用绿色胶囊和亮点；未知国家、`XX` 和 `T1` 不显示国家信息。浏览器不支持 `Intl.DisplayNames` 时保留国旗及国家代号。

`GET /api/bootstrap` 在原有字段之外返回 `client_ip`、`ip_proto`、`country`。使用有效的 `CF-Connecting-IP`，否则从 `X-Forwarded-For` 取首个有效 IPv6，再取首个有效 IP，最后使用连接对端地址。IP 通过 Python 标准库 `ipaddress` 校验；国家代码来自 `CF-IPCountry`，不调用外部 IP 定位服务。

这些代理请求头仅用于展示，不改变认证、限流和权限判断。部署时应由可信 Cloudflare / 反向代理覆盖这些请求头；允许客户端直连源站时，客户端可能伪造展示值。这里展示的是本次请求的连接地址，不能探测客户端未使用的另一种协议。

手机端（600px及以下）在登录页和工作区的整页页脚末尾显示徽章，隐藏故事栏与侧边栏中的副本。电脑登录页将徽章和说明固定排在故事栏内容的最底部；电脑登录后保持在左下角便笺与账户信息上方。平板的收窄侧边栏分行展示并提供完整悬停提示。
