# 学校与平台自定义（v0.3.0）

“账户与同步”顶部只有一个学校选择器，控制该用户的三种接入方式。内置山东理工大学；自定义仅用于相同后端协议的不同部署，不能凭一个域名兼容任意教务产品。

## 平台承接商与适配边界

| 入口 | 适用产品 / 承接商 | 已适配协议 | 证据边界 |
| --- | --- | --- | --- |
| App | 联奕系移动校园与兼容课表 H5 | mobileapi_ydxy RSA/AES 登录、H5 token 交换、逐周课表 | 接口与 App 包名特征推断；H5 可能由不同承接商提供，仍须接口一致 |
| 教务 | 正方软件新教务系统 | jwglxt RSA 登录、kbList/jcs/zcd 排课查询 | 山东理工大学教务处官方标明正方；不适配旧正方、强智、青果、树维等其他接口 |
| 实验 | 中新天达 ZXTD 系实验教学平台 + 金智 CAS 风格统一认证 | 当前 HMAC 签名、CAS ticket 交换、学生课表分页、AES-CBC 登录表单 | ZXTD 品牌与中新天达关系有高校采购资料；本校承建商、CAS 归属按接口特征识别，非采购合同确认 |

只对山东理工大学完成过真实登录和课表拉取。不同学校即使厂商相同，也可能改变路径、认证流程、签名密钥版本或响应字段；应先使用“测试课表拉取”验证，不能保证只改域名就成功。

参考来源：[山理工教务处](https://jwch.sdut.edu.cn/)、[联奕 CIO 的公开介绍](https://zzrvtc.edu.cn/_upload/article/files/df/27/fb60c80e4ba8b94388f36112833f/ee674d81-62e5-43e6-af4f-00b4d7927f87.pdf)、[高校 ZXTD 采购结果](https://purchase.lsnu.edu.cn/info/1012/3146.htm)。这些来源不能替代目标学校具体部署的协议验收。

## 填写方式

| 参数 | 填法 / 示例 |
| --- | --- |
| 学校名称 | 本校显示名称 |
| App 服务地址 | 协议、域名、可选端口，例如 https://mcp.example.edu.cn:8080；不带接口路径，旧版可为 HTTP |
| 课表 H5 API 基址 | https://schedule.example.edu.cn/schedule/api；保留 API 前缀 |
| 学校代码、YYID | 从本人学校 App 请求、应用列表获取，不沿用 SDLG 或山理工应用编号 |
| token 交换路径 | 从本校 H5 交换请求获取；/sys/security/login_sdutapp 只是山理工参考值，可修改 |
| 客户端版本 | 同协议 App 使用的 clientVersion，默认 3.2.0 |
| 教务系统基址 | https://jw.example.edu.cn/jwglxt；保留部署前缀，不填具体登录页 |
| 校区编号 | 教务节次时间查询的 xqh_id；学期编码在学期设置中填写 |
| 实验平台 API 基址 | https://lab.example.edu.cn 或带部署前缀的 API 地址；不填 /TEACH/# 前端路由 |
| 实验 CAS 入口 | 相对实验基址的入口，参考 /zxcas |
| 统一认证基址 | https://auth.example.edu.cn/authserver；与实验域名分开配置 |

只填写自己使用的平台即可。仅复用 App token 拉取时，只需 H5 基址；手动获取 token 还需 App 服务、学校代码、YYID 和交换路径。实验须同时配置实验与统一认证。未填写的入口会提示未配置，不会向山理工发送凭据。

## 学期与作息

不同学校须自行核对学期、第一周星期一、总周数、教务学期编码和校区。作息编辑入口位于“自定义 → 核对本校作息时间”；每行按以下格式填写，教学和实验共用：

```text
1 08:00 08:45
2 08:55 09:40
11-12 21:05 22:45
```

首次自定义沿用现有山理工作息作为参考，请按本校修改。单节时间与连续节次覆盖分开保存；某节缺失或与教务节次时间冲突时拒绝生成，不猜测。学期日期与时区、提醒、每周和单双周规则沿用已有转换器。

## 保存、测试与凭据

配置位于当前用户 settings.config 的 school_profile / school_custom；作息位于 periods / period_ranges。测试临时采用表单配置与当前填写的凭据，不保存或更新订阅。如果目的学校改变，测试不会复用旧学校密码或 token；须重新填写。

保存或登录更换目的地址、学校代码等连接参数时，清除旧学校凭据、身份、教师缓存和课表，并轮换三个订阅地址。仅更改学校显示名称不会清除。定时与手动任务按本人保存的配置执行，App token 失效锁定和只向教务故障转移的规则不变，实验仍独立。

请求只允许所配置域名；自定义域名解析到本机、内网或保留地址时拒绝，并将验证后的 DNS 地址固定到连接，避免解析变化。保留 HTTPS 证书校验，不绕过验证码、短信或额外认证。

## 订阅页面

ICS 标签保留聚合、教学、实验顺序，增加 iPhone/iPad、Mac、安卓说明。安卓无原生订阅入口时可用 [ICSx⁵](https://icsx5.bitfire.at/)。苹果入口参考 [Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/iph3d1110d4/ios)。下载 .ics 后导入只保留一次性副本，客户端订阅才会继续刷新。

CalDAV 标签只展示“正在开发，敬请期待”，没有实现 DAV 路由、认证或双向同步。
