# 普通用户密保找回

普通用户填写注册信息并点击创建后，弹出带现有入场动画的密保框。选择两道不同的常用问题并填写答案，可随账户一起保存；也可跳过后在「账户与同步 → 站内账户 → 设置密保问题」补设。补设或替换必须输入当前站内密码。管理员账户不开放密保找回。

登录页「忘记密码？」输入账户名后显示两道问题。两题都答对，并填写两次一致的新密码，即可重设站内密码。原密码无法读取。成功后清除该账户全部站内会话，需重新登录；学校凭据、课表、订阅链接不受影响。没有设置密保或忘记答案时联系站点管理员。

新增 `account_recovery` 表，启动自动创建，已有用户无需修改。答案经过 Unicode NFKC、大小写和连续空白规范化后，逐题使用独立随机盐及 scrypt 哈希，只保存问题代号和哈希；答案不返回到前端、不写入日志。答案长度2–128字符，新密码沿用10–256字符限制。

接口：

- `POST /api/register` 可带 `recovery: [{question, answer}, {question, answer}]`，账户和密保在同一事务创建。
- `POST /api/recovery/questions` 接收 `username`，返回两个 `{id, label}`。
- `POST /api/recovery/reset` 接收 `username`、`answers`（同上）和 `new_password`，校验并原子更新密码与撤销会话。
- `PUT /api/account/recovery` 要求登录和 CSRF，接收 `current_password` 与 `recovery`。
- bootstrap 返回常用问题清单，公开账户设置只返回是否设置密保，不返回答案或哈希。

找回接口检查来源；按对端连接和账户限流，每账户15分钟最多5次答案验证。密保设置每账户15分钟最多5次。找回接口对未知、停用、管理员、未设置密保账户均返回形状一致的题目响应，答案失败使用统一提示，并执行两次相同的 scrypt 工作。题目公开不等于账号验证成功。

密保答案应选择难被猜测的内容，不应重复站内密码；这也写入设置弹窗提示。找回流程只处理站内密码。
