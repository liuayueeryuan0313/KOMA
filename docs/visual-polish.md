# 统一视觉与动效（未发布）

- 登录页采用柔和渐变、输入框聚焦光晕及轻微入场动画；登录、注册切换时使用短过渡。
- 按钮统一悬停阴影、轻微抬起和按下缩放，侧栏选中状态与交互反馈更清晰。
- 内容卡片统一圆角和柔和阴影，页面切换使用短淡入与轻微位移。
- 弹窗使用淡入、轻微缩放和背景虚化过渡，提示消息使用短入场动画，登录错误有轻微反馈。
- 页面动效只在导航切换时播放，定时刷新数据不反复播放；右下角固定加号不参与页面位移动画。
- 尊重 `prefers-reduced-motion`，关闭 JS 入场动画及 CSS 动画、位移反馈，保留静态焦点和状态样式。

本机浏览器已核对登录、课表导航、新建弹窗与关闭操作；15 项 Node 测试通过，JavaScript 语法与差异格式检查通过。未构建、提交、推送或部署。
