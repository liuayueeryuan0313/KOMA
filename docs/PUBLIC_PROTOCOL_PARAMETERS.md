# 公开接口参数与发布范围

本项目的默认配置包含山东理工大学平台的服务地址和接口协议，用于复现本人授权的课表查询。它们不包含任何学生账户、密码、Cookie、会话 token、私密订阅链接或数据库密钥。

教务系统与实验平台为学校公开提供的登录入口：

- [学校教务通知中的教务系统地址](https://jwch.sdut.edu.cn/2026/0921/c5200a572566/page.htm)
- [实验教学综合管理系统](https://syjxgl.sdut.edu.cn/)
- [统一身份认证](https://authserver.sdut.edu.cn/authserver/login)

App 服务地址、学校代码、H5 地址、客户端版本与接口路径是客户端接入参数，不是个人凭据；读取课表仍需本人有效认证。

实验签名算法中的两个静态参数来自无需登录即可获取的学校客户端 JavaScript。2026-10-16 已核对登录页引用的公开资源：

`https://syjxgl.sdut.edu.cn/COMMON/js/COMMON.1788933219194.js`

公开资源中包含 `lab-core.mjs` 所用的两个参数；它们不是学生密码或服务端私钥，也不能替代服务端身份认证。公开资源文件名可能随平台升级改变，适配器不包含该 JavaScript 原文件。

验收报告公开版本已移除作者的实际局域网地址与个人课表统计。README 的局域网 IP 和安全测试中的 IP 是说明或测试样例，不是作者部署信息。实际运行数据、抓包与账户文件未纳入本仓库。
