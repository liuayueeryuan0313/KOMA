# 版本胶囊与更新检测（未发布）

顶部“关于”左侧显示圆角版本胶囊：左侧为状态光点，后面显示当前运行版本。

- 已检测且无需更新：绿色发光点。
- 有更高的正式版本：红色发光点，并显示红色“可更新”。
- 正在检测：状态点轻微脉动，暂时禁用重复点击。
- 未检测、检测失败或尚无公开正式版本：灰点，不误报最新。

进入已登录界面会自动检测一次。点击胶囊或关于页的“检测更新”，可查看当前版本、最新正式版本及发布页。只读取公开发布信息，不下载、安装、重启、构建或部署，不把学校账户、课表、凭据或私密订阅链接发送给 GitHub。

`app_version.py` 是运行版本的唯一来源，供健康检查、bootstrap、关于页和顶部胶囊使用。源码版本已更新到 0.4.0，尚未发布。登录页同时显示版本和镜像构建日期；构建日期来自镜像内的 `build-info.json`，由 Docker 构建步骤一次性写入。CI 为多架构镜像传入同一个 UTC 时间，本地直接构建则在构建时记录。源码预览显示“待构建（开发预览）”，不把启动时间或源码修改时间当作构建时间。日期按北京时间显示，完整时间可悬停查看。生成文件不纳入 Git 或 Docker 上下文，版本不匹配或元数据无效时显示开发预览。

后端登录保护接口为 `GET /api/updates`，使用固定仓库 `liuayueeryuan0313/KOMA` 的最新公开正式 Release。采用语义化版本比较，忽略草稿和预发布版本；网络超时为 8 秒，响应大小上限为 256 KiB。成功结果缓存 5 分钟，失败结果缓存 30 秒，避免短时间重复请求触发限流。

GitHub 接口依据官方说明：https://docs.github.com/en/rest/releases/releases#get-the-latest-release 。

验证：61 项 Python、15 项 Node 测试通过，覆盖版本比较、预发布及无效版本、缓存、网络错误、GitHub 限流及登录保护。本机浏览器成功完成真实 GitHub 检测，显示绿色状态并打开检测结果弹窗。未编译、提交、推送或部署。
