# 可配置日历提醒（未发布）

在“账户与同步”的“日历提醒”卡片中，可独立开启或关闭提前提醒，并设置提前分钟数。时长允许 1–10080 的整数（最多 7 天）；关闭时保留最后保存的时长，重新开启后可以继续使用。

点击“保存提醒设置”只保存当前账户的提醒偏好，不提交其他学校配置、学号或密码。保存时会在同一数据库事务中更新已有的教学、实验及聚合 ICS 订阅，无需重新向学校拉取。课程时间、课次、UID 及私密订阅地址保持不变。日历客户端需要刷新订阅后才会获取新的提醒配置；客户端自行添加的通知由客户端控制。

旧账户缺少这两个配置字段时，沿用开启提醒、提前 20 分钟的默认值。之后可以自行调整。新拉取课表和手动创建、修改的课次都使用本人保存的偏好。

## 配置与接口

- `config.reminder_enabled`：布尔值，默认 `true`。
- `config.reminder_minutes`：1–10080 的整数，默认 `20`。
- 沿用 `PUT /api/settings`，请求仅需包含要修改的提醒字段；省略的字段保留原值。
- 开启提醒时，每个 ICS 事件写入 `ACTION:DISPLAY` 和相应的 `TRIGGER;RELATED=START:-PT{分钟数}M`；关闭时不写入 `VALARM`。

## 验证

55 项 Python、15 项 Node 测试通过。本机浏览器使用虚构课表验证了修改分钟数、独立保存、关闭后禁用输入，以及订阅中的提醒同步更新。未构建镜像、提交、推送或部署。
